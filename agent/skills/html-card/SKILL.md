## Step — write the card

Write an HTML card in the current working directory named `YYYY-MM-DD-title.html`.

**Done when:** the file exists in cwd.

## Reference — HTML

- Fully self-contained. No CDN, no external assets.
- System font stack. No webfonts.
- Design for reading, not decoration. No gradients, stacked box-shadows, or backdrop-filter.
- Readable on a phone.
- Citations are links. Footnotes point at original URLs.
